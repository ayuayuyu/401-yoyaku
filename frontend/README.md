# 401号室予約管理アプリケーション フロントエンド

このリポジトリは、401号室の予約を管理するアプリケーションのフロントエンドです。  
フロントエンドには Next.js を使用しています。

## セットアップ手順

### 1. 必要なパッケージのインストール

```bash
pnpm i
```

### 2. アプリケーションの起動
```bash
pnpm run dev
```
ブラウザで`http://localhost:3000`にアクセスしてください。

## Docker起動

`yoyaku-backendo` の `docker-compose.yaml` からフロントエンドも同時に起動できます。  
（`yoyaku-backendo` と同階層にこのリポジトリがある前提）
